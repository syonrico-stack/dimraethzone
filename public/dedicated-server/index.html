Dimraeth Dedicated Servers: Official Status + the Waygate Option

The official answer and the community answer are different — and most sites only tell you one of them. Here's the complete picture for running a persistent Dimraeth world.

Official: P2P only (EA)Community: WaygatePlayers: 1–8

Quick answer

Officially, Dimraeth EA uses peer-to-peer drop-in co-op: the world lives on the host's machine, and when the host logs off, the world sleeps. There is no official dedicated server yet. Unofficially, the open-source Waygate project lets you run a persistent Dimraeth server that stays online when nobody is logged in — and game-server hosts have started offering one-click Dimraeth servers based on it.

Remember how Dimraeth saves work regardless of option: your character follows you between worlds, while the world state follows the host (or the server). A dedicated server solves the world's availability — your character progress was never the problem. Full mechanics in the co-op guide.

Waygate: what it is and what to expect

Waygate is an open-source, community-built dedicated server implementation for Dimraeth — the headline feature being a world that keeps running even when nobody is logged in. It's early software: expect manual setup (command line, ports, config files), rough edges after game patches, and no official support from Mudtek. If you've ever run a Valheim or Palworld server, the shape of the job will feel familiar.

  • Self-host: run it on a home machine that's always on, or rent a small VPS.
  • Managed hosting: providers like SurvivalServers began listing Dimraeth servers within days of EA launch — one-click setup, per-slot pricing.
  • Save-sharing alternative: if all you want is "let my friend host while I'm away", tools like savesync games (community save-sync) can hand the world file between hosts — clunkier than a server, but zero setup.

Will there be official dedicated servers?

Mudtek's EA FAQ describes the multiplayer model as P2P and hasn't promised dedicated servers on the public roadmap — the roadmap is focused on content (Q4 2026 patch, new races/classes, Act 2 in 2027). Historically, co-op survival games of this size tend to ship official server support around 1.0 if community demand stays loud. We'll update this page the moment the official answer changes.

Honesty box: Waygate and third-party hosting are community solutions, not endorsed or supported by Mudtek. Details verified late September 2026 — this corner of the ecosystem moves fast, so check project pages for current setup guides before a Saturday-night install session.

FAQ

Does Dimraeth have dedicated servers?
Not officially — Early Access multiplayer is peer-to-peer, with the world stored on the host's machine. The community-built open-source Waygate project adds unofficial dedicated servers, and paid hosts have started offering Dimraeth server rental.
Can a Dimraeth world stay online when the host logs off?
With official P2P hosting, no — the world sleeps when the host leaves. A Waygate dedicated server (self-hosted or rented) keeps the world running 24/7 even when nobody is logged in.
How many players can play Dimraeth co-op?
1–8 players with drop-in/drop-out co-op. Your character and its progress follow you between worlds; the world state belongs to the host or server.
Is Waygate safe to use?
It's an open-source community project with no anti-cheat conflicts, but it's unofficial and early — back up your world, expect breakage after game patches, and follow the project's own setup docs.
